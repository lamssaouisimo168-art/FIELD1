# README - Élan Fitness


Ce projet consiste à améliorer un site web de fitness et son design.



### HTML

* Créer des titres et des paragraphes.
* Ajouter des images et des liens.
* Créer des sections et des formulaires.

### CSS

* Changer les couleurs et les polices.
* Organiser les éléments avec Flexbox.
* Utiliser les marges et les espacements.
* Faire des animations simples.
* Adapter le site aux téléphones et aux ordinateurs avec les Media Queries.

## Outils utilisés

* Visual Studio Code
* Navigateur web
* Git et GitHub

## Conclusion

Ce projet m'a aidé à pratiquer HTML et CSS et à mieux comprendre comment créer un site web. Je dois encore apprendre et pratiquer pour améliorer mon niveau.
