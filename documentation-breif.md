# Documentation du projet Élan Fitness

## 1. Présentation du projet

Ce projet consiste à améliorer un site web dédié au fitness afin de le rendre plus moderne, plus clair et plus agréable à utiliser.

L'objectif est de présenter les activités de la salle de sport, d'améliorer l'organisation des pages et de faciliter la navigation des utilisateurs.

## 2. Technologies utilisées

### HTML5

J'ai appris les bases du HTML pour structurer les pages du site web.

Les principales notions étudiées sont :

* Les titres et les paragraphes.
* Les liens de navigation entre les pages.
* L'intégration des images et des logos.
* Les listes et les sections.
* La création de formulaires de contact.
* L'utilisation des attributs HTML.

### CSS3

J'ai appris les bases du CSS pour améliorer le design et la mise en page du site.

Les principales notions étudiées sont :

* Les couleurs et les arrière-plans.
* Les polices et les tailles de texte.
* Les marges, les espacements et les bordures.
* L'utilisation de Flexbox pour organiser les éléments.
* La création de mises en page en colonnes.
* Les Media Queries pour adapter le site aux différentes tailles d'écran.
* Les animations et les transitions simples.

## 3. Responsive Design

J'ai découvert le principe du Responsive Design, qui permet d'adapter l'affichage d'un site web aux différents appareils : ordinateur, tablette et téléphone.

J'ai commencé à utiliser les Media Queries pour ajuster la mise en page en fonction de la largeur de l'écran.

## 4. Animations et effets visuels

J'ai appris les bases des animations CSS et des transitions simples pour améliorer l'apparence du site et rendre certains éléments plus agréables à utiliser.

## 5. Outils utilisés

* **Visual Studio Code :** pour écrire et modifier le code HTML et CSS.
* **Navigateur web :** pour visualiser et tester le site.
* **Git et GitHub :** pour gérer les versions du projet et sauvegarder le code.

## 6. Compétences acquises

Ce projet m'a permis de comprendre les bases de la création d'un site web avec HTML et CSS, d'améliorer la mise en page et de découvrir le Responsive Design.

J'ai également appris à organiser les fichiers du projet, à rechercher des solutions aux problèmes rencontrés et à corriger certaines erreurs.

## 7. Conclusion

Ce projet représente une étape importante dans mon apprentissage du développement web. Il m'a permis de mettre en pratique les bases du HTML et du CSS, de découvrir Flexbox, les Media Queries et les animations simples.

Mon objectif est de continuer à pratiquer pour améliorer mes compétences et créer des sites web plus modernes et responsives.
